# Claude artefactos · XD

Prototipos y herramientas del equipo XD (Entretenimiento).

| Carpeta | Qué es |
|---|---|
| `polaris-movil-tablet/` | Simulador Polaris móvil y tablet (vertical/horizontal) con cuadro de mandos |
| `nueva-tab/` | Aplicación móvil – nueva tab bar |
| `recorte-avatares/` | Recorte por lotes de avatares BOB-BBOB a 392×536, con informe y renombrado por CSV |

Cada carpeta es una página HTML autocontenida: abre su `index.html` en el navegador.

Notas:
- Polaris usa una función de Claude (preguntar a Claude) que no funciona fuera de claude.ai; el resto sí.
- El recorte de avatares descarga el ZIP directamente en el navegador.
