# Artefactos XD

Prototipos y herramientas del equipo de eXperience Design (Entretenimiento). Portada: `index.html`.

| Carpeta | Qué es |
|---|---|
| `polaris-movil-tablet/` | Simulador Polaris en móvil y tablet (vertical/horizontal) con cuadro de mandos |
| `nueva-tab/` | Simulador BBOB Mobile con la nueva tab bar |
| `webgl-shaders/` | Carrusel WebGL para TV con shaders |
| `recorte-avatares/` | Recorte por lotes de avatares BOB-BBOB a 392×536, con informe y renombrado por CSV |

Cada carpeta es una página HTML autocontenida.

**Web:** https://davmorser1.github.io/Claude_artefactos/ (GitHub Pages desde `main`, carpeta raíz).

Nota: las funciones que preguntan a Claude (Polaris) solo funcionan dentro de claude.ai.
